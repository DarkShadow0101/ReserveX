## 💡 Key Concepts to Keep in Mind

### 1. Integer Paise for Money
The backend stores all prices in **integer paise** (to avoid floating-point math bugs like `0.1 + 0.2 = 0.30000000000000004`):
- `₹1 = 100 paise`
- When displaying to users, always use `formatPaiseToINR(paise)` from `src/utils/currency.js`.
- When organizers enter `₹999`, we multiply by 100 (`99900 paise`) before sending it to the backend.

### 2. The 10-Minute Booking Hold
- When a customer clicks "Reserve Tickets", the server creates a **temporary hold** on that inventory for 10 minutes.
- The server returns `holdExpiresAt`.
- The checkout page uses `useCountdown(booking.holdExpiresAt)` to display the live timer countdown.
- If the customer doesn't pay in 10 minutes, the hold expires and seats are automatically restored for other buyers.

### 3. Signed QR Codes
- Every digital ticket has an HMAC-SHA256 signed `qrToken` generated by the backend.
- We render this token using `qrcode.react`.
- At the venue entrance, staff scan this token using `html5-qrcode` in the Check-In Station.
- Once checked in, scanning it a second time returns `409 Conflict` (single-use enforcement).

## 🚀 How to Run Locally

### Step 1: Start the Backend (Terminal 1)
```bash
cd server
npm install
npm run dev
# Backend API runs on http://localhost:5000
```

### Step 2: Start the Frontend (Terminal 2)
```bash
cd client
npm install
npm run dev
# Frontend runs on http://localhost:5173
```

Open your browser at `http://localhost:5173` to view the app!
